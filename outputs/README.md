# Aggregate outputs

Only aggregate, non-identifiable outputs are stored here.

## `model_evaluation/`

- `AIBM_development_test_key_distributions.csv` — development/test composition checks for outcome, sex, residence and age groups.
- `AIBM_primary_cohort_predictor_characteristics.csv` — analytic-cohort distributions and missing/special-code handling for the 17 primary predictors.

## `prior_status_sensitivity/`

- `AIBM_known_status_eligibility_counts.csv`
- `AIBM_known_status_sensitivity_summary.csv`
- `AIBM_known_status_sensitivity_fold_metrics.csv`
- `AIBM_known_status_sensitivity_subgroups_24_3pct.csv`
- `AIBM_known_status_sensitivity_split_optima.csv`

The local publication package also contains a full sensitivity capacity curve. That file can be added in a later repository pass together with the original source code and final figure binaries.

No respondent-level records or DHS microdata are stored in this repository.
