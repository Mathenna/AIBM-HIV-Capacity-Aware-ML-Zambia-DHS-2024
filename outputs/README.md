# Aggregate outputs

Only aggregate, non-identifiable outputs are stored here. Raw DHS microdata, split assignments, per-record probability arrays and fitted model objects are intentionally excluded.

## `model_evaluation/`

- `AIBM_development_test_key_distributions.csv` — development/test composition checks for outcome, sex, residence and age groups.
- `AIBM_primary_cohort_predictor_characteristics.csv` — analytic-cohort distributions and missing/special-code handling for the 17 primary predictors.

## `prior_status_sensitivity/`

Publication-specific sensitivity excluding respondents who self-reported a prior positive HIV test result from eligibility while never using that field as a model predictor.

- `AIBM_known_status_eligibility_counts.csv`
- `AIBM_known_status_sensitivity_summary.csv`
- `AIBM_known_status_sensitivity_fold_metrics.csv`
- `AIBM_known_status_sensitivity_subgroups_24_3pct.csv`
- `AIBM_known_status_sensitivity_split_optima.csv`

## `reproducibility/`

Audited aggregate snapshots produced while validating the public publication code against the authorised local Zambia DHS files. These include:

- analytic-sample and cluster-exclusive partition summaries;
- zero cluster/household overlap checks;
- final-test discrimination and Brier score;
- exact 24.3% final-test confusion counts and operating-point metrics;
- alternative F2/F1/Youden and fixed-threshold operating criteria;
- selected-capacity subgroup audit;
- calibration diagnostics;
- five-fold weighted-XGBoost stability summary;
- pooled outer-fold subgroup recall;
- domain-only and leave-one-domain-out performance;
- `reproducibility_verification.csv`, containing the locked-result audit checks.

The complete 491-point capacity curve and longer intermediate files are generated locally by `python src/analysis_pipeline.py`. They are not required to expose respondent-level records and can be regenerated by authorised DHS users.

No respondent-level records or DHS microdata are stored in this repository.
